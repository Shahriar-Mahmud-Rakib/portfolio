## 🌟 Key Highlights & Features

- **Cyber-Clean Glassmorphism UI**: Built with a sleek dark slate theme, neon accents (`#00F59B`), subtle ambient glows, and responsive layout.
- **Dynamic Typewriter & Hero Stats**: Interactive animated metrics showing 500+ test cases executed, 120+ defects caught, and 35+ APIs validated.
- **STLC & QA Workflow Showcase**: Visual breakdown of the 5-step Software Testing Life Cycle (Requirement Analysis → Test Planning → Execution → Defect Tracking → Sign-off).
- **Interactive Skills Filter**: Filter testing skills by category (*Manual QA, API & Performance, Tools & Defect Mgmt, Database, Business Analysis*).
- **Experience Timeline**: Career history with measurable achievements and technology tags.
- **Interactive Projects & Detail Modals**: Deep-dive case studies with test scopes, deliverables, tools used, and popup modals.
- **Verified Certifications**: Quick verification links to Coursera, Atlassian, and Eduonix credentials.
- **Click-to-Copy & Working Contact Form**: 1-click clipboard copy for email & phone with toast alerts, and FormSubmit integration.
- **WhatsApp Quick Chat**: Floating action button with pulse animation and tooltip.
- **SEO & Schema.org Optimized**: Full OpenGraph meta tags, Twitter cards, and structured JSON-LD schema for search visibility.
